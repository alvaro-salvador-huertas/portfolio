About

I’m a third-year Computer Engineering student at the University of Granada. I develop Python tools that integrate AI agents into workflows for querying documentation, planning, development and code review.

My projects combine Codex CLI, context versioned in Git, structured outputs and independent evaluation. I use acceptance criteria, automated tests and GitHub Actions to check generated changes and retain evidence before integration under human supervision.
