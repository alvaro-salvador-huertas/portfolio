01 / Featured project

Learning prototype · In development

git-docs-agent

Git questions. Local notes.
Answers worth examining.

The problem

Can a small assistant answer Git questions from a limited set of notes and recognise when those notes don't contain enough information?

How it works

A Python terminal program prepares five local Git notes and calls Codex CLI. Its instructions ask for answers in Spanish, source citations, and an acknowledgement when the documentation is insufficient. Execution logs help trace what happened in each run.

What I'm learning

Separating program tests from answer evaluation, investigating errors through logs, and refining instructions based on evidence.

  • Python
  • Codex CLI
  • Markdown
  • unittest
Explore git-docs-agent on GitHub ↗

An early evaluation, with open questions.

The first review found an answer that read the relevant note but omitted required concepts. A revised prompt was tried on two cases; three others still need to be rerun. This limited evidence does not establish general reliability.
